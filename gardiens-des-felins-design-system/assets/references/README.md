# Références visuelles — Gardiens des Félins

## Visuels symboliques recommandés

| Type | Usage |
|---|---|
| Silhouette d'animal | Accroche, contexte |
| Ombre portée | Mystère, présence |
| Écran avec croix / blocage | Contenu bloqué en ligne |
| Globe / réseau | Dimension numérique |
| Patte / empreinte | Identité animale |
| Barreaux / clôture | Captivité |
| Lumière froide | Dénonciation, exposition |

## Banques d'images gratuites

- **Unsplash** : unsplash.com
- **Pexels** : pexels.com
- **Canva Elements** : directement dans Canva
- **Pixabay** : pixabay.com

## Mots-clés recommandés

```
dark animal silhouette  |  shadow cat dog
animal freedom  |  cage bars
night street animal  |  digital network globe dark
blurred screen  |  animal paw print dark
```

## À NE PAS utiliser

- Images de souffrance animale directe
- Photos de maltraitance ou blessures
- Images sans droits vérifiés
- Screenshots de contenus violents
