# Logos — Gardiens des Félins

## Logo officiel

URL hébergé : https://i.imgur.com/JPdiSHg.jpeg

## Consignes d'utilisation

- Toujours sur fond sombre (`#11110D` ou `#181A1A`)
- Taille minimale : 60px de côté
- Ne pas déformer, recolorer ou ajouter d'ombre portée
- Version circulaire pour les slides CTA et stories

## Dans Canva

1. Téléversez depuis l'URL ci-dessus
2. Ajoutez au kit de marque Canva
3. Utilisez sur chaque slide CTA finale (slide 8)
