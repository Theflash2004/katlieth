# Polices — Gardiens des Félins

## Polices officielles

### Titre : Playfair Display Bold
- Source : https://fonts.google.com/specimen/Playfair+Display
- Fallback : Georgia Bold
- Usage : Tous les titres de slides, CTA headlines

### Corps : Inter Regular / SemiBold / Bold
- Source : https://fonts.google.com/specimen/Inter
- Fallback : Arial, Helvetica
- Usage : Eyebrows, corps de texte, footers, CTA actions

## Import Google Fonts

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&family=Playfair+Display:wght@700;800&display=swap" rel="stylesheet" />
```

## Styles Canva à sauvegarder

- **Headline** : Playfair Display Bold 44px `#F2EFE6` uppercase
- **Eyebrow** : Inter SemiBold 13px `#B65A2B` uppercase
- **Body** : Inter Regular 20px `#B8B1A5`
- **CTA** : Inter Bold 22px `#F2EFE6` uppercase
- **URL** : Inter Regular 16px `#D19A3A`
- **Footer** : Inter Regular 11px `#B8B1A5`
